        OAuth Workbench — Pentester Reference
        
      

      

        

          

            
1. Typical Pentest Workflow

            
    
              
  • Discover: Enter an Issuer URL to fetch /.well-known/openid-configuration.
    • 
              
  • Paste & Load: Paste an Authorization URL or raw Burp HTTP request at the top to parse parameters and load it into the Repeater.
    • 
              
  • Trace & Visualize: Send requests with Follow redirects enabled to inspect every 302 Location hop, headers, and cookies.
    • 
              
  • Interactive Login: Use Open in Browser with redirect_uri=http://localhost:3000/callback; callbacks & #fragment tokens stream in live via SSE.
    • 
            

          

          

            
2. Redirect-URI Batch Probe Verdicts

            
    
              
  • ACCEPTED_WITH_CREDENTIAL Server redirected to attacker/mutated URI with code, access_token, or id_token.
    • 
              
  • ACCEPTED_REDIRECT Server redirected to attacker/mutated URI without an error= parameter.
    • 
              
  • REDIRECT_ERROR Server returned 3xx containing error=.
    • 
              
  • BLOCKED Server rejected the mutated redirect_uri (e.g. HTTP 400).
    • 
            

          

          

            
3. Cookies & Session Jar

            
    
              
  • Cookies Set: Every Set-Cookie header is parsed into flags (HttpOnly, Secure, SameSite, Domain).
    • 
              
  • Session Cookie Jar: When enabled, cookies are scoped by domain/path and sent automatically across redirect hops and follow-up Repeater requests.
    • 
              
  • Baseline Diff: Click Set as Baseline in the Inspector to compare status, Location, and body length across mutated requests.
    • 
            

          

          

            
4. Local Mock IdP Sandbox

            
    
              
  • Available at /mock-idp/.well-known/openid-configuration.
    • 
              
  • Use the sidebar toggles to simulate misconfigurations (open redirect, missing state, Implicit downgrade, PKCE plain, alg: none).
    • 
              
  • Shortcut: Press ? anywhere outside inputs to toggle this help, Esc to close.
    •
